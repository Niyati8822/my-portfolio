# React Portfolio

This is a React-based portfolio website built with Create React App. The project showcases various skills and projects using modern React practices, including React Router for navigation and SCSS for styling.

## Project Structure

```
react-portfolio
├── src
│   ├── App.js               # Main application component with routing
│   ├── App.scss             # Global styles
│   ├── components            # Contains all React components
│   │   ├── EnergySphere     # 3D sphere component with skills
│   │   ├── Layout            # Layout component for wrapping content
│   │   ├── Sidebar           # Navigation component
│   │   ├── Skills            # Skills page component
│   │   └── Home              # Home page component
│   ├── assets                # Contains images and fonts
│   ├── setupTests.js         # Testing setup
│   └── index.js             # Entry point of the application
├── package.json              # Project dependencies and scripts
├── jsconfig.json             # JavaScript project configuration
└── README.md                 # Project documentation
```

## Features

- **Energy Sphere**: A visually engaging 3D representation of skills using Three.js.
- **Responsive Design**: The layout adapts to different screen sizes.
- **Navigation**: Easy access to different sections of the portfolio through a sidebar.
- **Testing**: Components are tested using Jest and React Testing Library.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd react-portfolio
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.
